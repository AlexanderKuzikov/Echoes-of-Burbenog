## Этот файл — единственный источник

Работать только по нему. Открывать свой модуль, `src/main.ts` (только чтобы понять, как модуль

## Твоя работа

Враг должен читаться с одного взгляда и отличаться от двух других видов. Сейчас это
икосаэдр с конусом и полоской здоровья, три оттенка, масштабы 0.84 / 0.68 / 0.76. Задача — сделать
из этого вид, а не набор примитивов.

**Владение: только `src/client/enemies.ts`.** Больше ты не правишь ничего.

## Что менять можно и нужно

- Форму врага: пропорции, число и форма частей, силуэт. Три вида должны различаться силуэтом, а не
  только оттенком — на тёмной скале оттенок не читается.
- Масштаб и пропорции — с оглядкой на коридор шириной 1.2 и на то, что враг идёт по ленте дороги.
- Материал: roughness, metalness, emissive, вес пробы через `withProbeWeight` из `./shared.ts`.
  Роли проб объявлены там; **новую роль в `shared.ts` не заводи** — бери одну из существующих,
  иначе три параллельные сессии будут править один файл.
- Idle bob и вращение — в `animate`, там же обязательная проверка `reducedMotion`.

## Что менять нельзя — иначе сломаешь соседей

1. **Сигнатура `EnemyPresentation` и `EnemyView` — как есть.** `main.ts` вызывает
   `applySnapshot`, `animate`, `positionOf`, `viewCount`, `positions`, `bobOffset`,
   `setReducedMotion`, и читает `group`, `body`, `healthFill` из вида.
2. **`ENEMY_BASE_Y` не переименовывать и не убирать.** На ной держится вспышка убийства:
   `combat-fx.ts` импортирует эту константу. Значение менять можно, имя нельзя.
3. **Полоска здоровья.** Ею двигает сам модуль (`healthFill.scale.x` и `healthFill.position.x`
   считаются от левого края `-0.38` при ширине `0.76`). Если поменяешь геометрию полоски, пересчитай
   эти два числа в том же модуле, иначе урон будет съезжать.
4. **Замедление должно оставаться видно** — эмиссия тела поднимается с 0.45 до 1.15 при `slowTicks`.
   Это единственный признак, по которому игрок видит, что враг замедлён.
5. **Никаких новых зависимостей и никаких внешних текстур.** Только примитивы Three.js.
6. **Никаких новых тестов.**

## Ошибка, на которую уже наступали

Комментарий `//` в `src/styles.css` — не комментарий: минификатор съедает следующий селектор,
`npm run build` падает с `Invalid empty selector`, а `npm test` остаётся зелёным. Стили ты не
трогаешь, но `build` проверять обязательно — `npm test` этому не поверит.

## Git

Ветка `main`, коммитить только свой файл поимённо, `git add -A` запрещён. Перед коммитом —
`git status` и `git diff`. Перед push — `git pull --rebase origin main`: две сессии пушат в одну
ветку, и твоя правка должна лечь поверх чужой. Если при rebase есть конфликт — **остановись,
не разрешай силой**, напиши в отчёт. Строгий UTF-8.

## Форма отчёта

Отчёт дописывается в конец **этого файла**, статус меняется на `на проверке`. В отчёте: что
изменил и почему так читается, три вида до и после словами, что не смог сделать и почему, какие
чужие файлы тебе понадобились и что ты НЕ стал делать. Скриншоты — рядом ссылкой на папку.

Принимает владелец, и он решает по игре, а не по отчёту.
