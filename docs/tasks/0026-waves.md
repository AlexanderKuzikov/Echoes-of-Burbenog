## Задача

Сейчас в игре одна волна: 16 врагов, победа за 20–35 секунд, и ни о чём после этого не думаешь.
Нужно **8–10 волн, которые меняются и усиливаются**, и решение, которое принимается на каждой.

**Владение: `src/game-core/contact.ts`.** Больше ты не правишь ничего.

## Что именно сделать

**Семь видов врагов, все в сегодняшней схеме** — `maxHealth`, `speed`, `reward`, `coreDamage`,
`tags`. Ни одного нового поля в типах.

| id | Роль |
|---|---|
| `husk` | земля, базовый танк |
| `runner` | земля, быстрый |
| `wisp` | воздух, бьёт только `grove-lens` |
| `swarmling` | земля, очень быстрый и очень слабый, идёт стаями |
| `carapace` | земля, медленный, огромное здоровье |
| `mote` | воздух, дешёвый, идёт вместе с `wisp` |
| `maw` | босс, только на последней волне |

**Волны меняются составом и объёмом, а не новыми правилами:** доля воздуха, плотность, скорость,
сколько стаями. Ранние волны должны быть проходимыми за счёт того, что врага пропускают и убивают
на следующем круге; поздние — за счёт того, что пропускать уже нельзя.

**Четыре маршрута, ids строго такие:** `burrow-north`, `burrow-east`, `burrow-south`,
`burrow-west`. Группы волны ссылаются на них, и на первых волнах враг должен идти со **всех четырёх
сторон сразу** — это и есть «пришёл с четырёх углов». `circuit: true` у маршрутов уже проставлен
работой `0025`, тебе его не трогать.

**Подготовка между волнами** сейчас 30 тиков, это 1.5 секунды — думать не о чем. Сделай её длинной,
чтобы между волнами можно было тратить золото. Сколько — твоё решение, обоснуй его числами.

## Проверка и замеры

```text
npm run typecheck
npm run build
```

`npm run test:core` **запусти и приведи числа**: он печатает `tick` и `gold` победного прогона, и
после твоих волн эти числа обязаны поехать. Это не поломка, это ожидаемое следствие нового
контента — напиши новые значения в отчёт.

**Главное, что ты обязан посчитать сам, потому что это и есть приёмка работы:**

1. **Сколько золота приносит каждая волна** и сколько башен на неё хватает при 12 местах. Без
   этого волны либо проходятся без единой башни, либо не проходятся вовсе, и оба варианта — мимо.
2. **Сколько кругов игрок пропускает в каждой волне при разумной защите.** Если это ноль на
   последней волне — волна слишком простая. Если больше двух — она не проходима.
3. **Полную длину матча** при средней игре, в тиках и в минутах. Владелец просил две минуты;
   честное число важнее желаемого, приведи и то и другое.

Свой dev-сервер: `npm run dev -- --port 5175`. Играть будешь сам, чтобы снять числа, и это
единственный способ их снять.

Скриншоты клади в `docs/tasks/0026-waves/`. В `docs/screenshots/` не пиши.
