# 0024 — Оформление карты

> Статус: выдана штабом, ждёт сдачи
> Приоритет: P0
> Идёт параллельно с `0022` (враги) и `0023` (башни)

## Этот файл — единственный источник

Работать только по нему. Открывать свой модуль, `src/main.ts` (только чтобы понять, как модуль
вызывается) и больше ничего.

## Твоя работа

Массив, в котором вырезаны ниши, — это девяносто процентов картинки. Сейчас это серые блоки четырёх
высот (0.34 / 0.68 / 1.4 / 1.95) на плоской земле. Задача — сделать так, чтобы игрок с первого
кадра прочитал: вот канал, вот его повороты, вот выемки, и вот куда он спрячет башню.

**Владение: только `src/client/map.ts`.** Больше ты не правишь ничего.

## Что менять можно и нужно

- **Материалы и цвет камня.** Сейчас четыре высоты делят `wallLowMaterial` и `wallHighMaterial`.
  Можно сделать больше материалов, если это читается лучше.
- **Вид земли и дороги.** Материал, эмиссия, ширина читаемого края ленты.
- **Пол ниш и круглая камера ядра.**
- **Свет.** Он в `main.ts` и заморожен, поэтому работай тем, что есть: материалы, roughness,
  metalness, эмиссия, вес пробы через `withProbeWeight` из `./shared.ts`. **Новую роль пробы в
  `shared.ts` не заводи** — бери одну из существующих, иначе три параллельные сессии будут править
  один файл.
- **Пады:** как читается свободное место, занятое и ошибка. Их состояния уже есть, вопрос в виде.

## Что менять нельзя — иначе сломаешь соседей и баланс

1. **Геометрию коридора не трогать.** Роад, ниши и ядро описаны в `src/game-core/scenario.ts`
   (`trainingCorridor`), и он заморожен. Это не формальность: на покрытии коридора из каждой
   ниши держится весь смысл выбора башни. Сместишь стены — поедут числа, и работа по башням,
   которую прямо сейчас делает соседняя сессия, станет неверной, а она об этом не узнает.
2. **Террасы остаются симметричными по глубине в камне.** Иначе стена встаёт поперёк дороги при
   повороте камеры — это ломало вид дважды, инвариант зафиксирован в `PLAN`.
3. **Сигнатура `MapPresentation` — как есть.** `main.ts` и seam читают `roadHalfWidth`,
   `routeLength`, `routeSegmentCount`, `wallBlockCount`, `openCells`, `bayCount`, `chamberRadius`,
   `corridorSamplePoints`, `distanceToRoad`, `corridorCoverage`, `pickTargets`, и вызывают
   `applySnapshot`, `animate`, `flashPadError`, `flashCoreDamage`, `resetCoreDamage`,
   `setReducedMotion`, `padCount`.
4. **`WALL_HEIGHTS` — как есть.** По ним считается кадр камеры: `measureCorridor` в `main.ts`
   меряет коридор по точкам выборки на высотах `0` и `WALL_HEIGHTS[0]`. Поменяешь первую высоту —
   поедет кадр.
5. **Камень перед нишей по-прежнему означает промах.** `pickTargets` должны оставаться теми же
   объектами в том же порядке — picking честный, трогать его нельзя.
6. **Никаких новых зависимостей и никаких внешних текстур.** Только примитивы Three.js.
7. **Никаких новых тестов.**

## Проверка

```text
npm run typecheck
npm run build
```

`npm test` запускай, только если свободен — сценарии делят каталог `test-results/` с двумя
параллельными сессиями. Существующие 48 сценариев проверяют форму модуля и геометрию ниш,
которые ты обязан сохранить, поэтому зелёный прогон здесь ничего нового не скажет.

Свой dev-сервер: `npm run dev -- --port 5176`. Две другие сессии сидят на `5174` и `5175`.

Посмотри результат с четырёх сторон: север, восток, юг, запад. Симметрия террас проверяется
только так — на углах скала не должна вставать поперёк дороги.

Скриншоты клади в `docs/tasks/0024-map-look/`, отдельной папкой, которую никто не займёт.
В `docs/screenshots/` не пиши — это зона штаба.

## Ошибка, на которую уже наступали

Комментарий `//` в `src/styles.css` — не комментарий: минификатор съедает следующий селектор,
`npm run build` падает с `Invalid empty selector`, а `npm test` остаётся зелёным. Стили ты не
трогаешь, но `build` проверять обязательно — `npm test` этому не поверит.

## Git

Ветка `main`, коммитить только свой файл поимённо, `git add -A` запрещён. Перед коммитом —
`git status` и `git diff`. Перед push — `git pull --rebase origin main`: две сессии пушат в одну
ветку, и твоя правка должна лечь поверх чужой. Если при rebase есть конфликт — **остановись,
не разрешай силой**, напиши в отчёт. Строгий UTF-8.

## Форма отчёта

Отчёт дописывается в конец **этого файла**, статус меняется на `на проверке`. В отчёте: что
изменил и что теперь читается, какие материалы и сколько их стало, что не смог сделать и почему,
какие чужие файлы тебе понадобились и что ты НЕ стал делать. Скриншоты — рядом ссылкой на папку.

Принимает владелец, и он решает по игре, а не по отчёту.
