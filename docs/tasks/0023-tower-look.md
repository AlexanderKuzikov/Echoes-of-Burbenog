# 0023 — Вид и анимация башен

> Статус: выдана штабом, ждёт сдачи
> Приоритет: P0
> Идёт параллельно с `0022` (враги) и `0024` (карта)

## Этот файл — единственный источник

Работать только по нему. Открывать свой модуль, `src/main.ts` (только чтобы понять, как модуль
вызывается) и больше ничего.

## Твоя работа

Башня должна отличаться от соседней и от врага силуэтом, а её выстрел — читаться. Сейчас три башни
собраны из цилиндра, цилиндра, конуса и октаэдра плюс тор, у настоящей `pulse-spire` скелетная
модель с клипом.

**Владение: только `src/client/towers.ts`.** Больше ты не правишь ничего.

## Что менять можно и нужно

- **Процедурный вид `grove-lens` и `frost-relay`.** Это твоя основная работа: сейчас они
  отличаются от `pulse-spire` только пропорциями и оттенком крыши.
- **`pulse-spire` — только посадка.** Настоящая модель приезжает из `public/models` и генерируется
  `scripts/build-assets.ts`. Тебе разрешено менять, как она стоит в нише: масштаб, поворот, высота,
  точка вращения. Саму GLB-модель не трогать — это отдельная работа, она трогает конвейер ассетов
  и артефакт, который проверяют 11 красных проверок.
- **Анимация.** Кристалл дышит в покое (`towerCrystalIdleIntensity` 2.4) и вспыхивает при выстреле
  (5.2) — это можно переделать, если станет выразительнее. Клип настоящей модели: фаза старта
  считается от порядка постройки (слот × 0.37 с), и это обещание реплею — не ломай его.
- **Наведение на цель.** Угол считается по позиции цели; если решишь вести луч иначе, скажи в отчёте.
- Материал: roughness, metalness, emissive, вес пробы через `withProbeWeight` из `./shared.ts`.
  **Новую роль пробы в `shared.ts` не заводи** — бери одну из существующих, иначе три параллельные
  сессии будут править один файл.

## Что менять нельзя — иначе сломаешь соседей

1. **Сигнатура `TowerPresentation` и `TowerView` — как есть.** `main.ts` вызывает `applySnapshot`,
   `animate`, `onFired`, `upgradeWithModels`, `resetFired`, `setReducedMotion`, `viewCount`,
   `positions`, `modelReadings`, `poseReadings`, `clipMotion`, и читает из вида `group`, `crystal`,
   `crystalBaseY`, `crystalMaterial`, `clip`, `firedUntil`, `aimAngle`, `release`, `source`,
   `modelId`, `towerId`.
2. **`onFired` возвращает две позиции — откуда вылетел снаряд и где попал.** Их рисует
   `combat-fx.ts`, и если поменяешь смысл, луч улетит мимо цели. Константы `towerMuzzleHeight` и
   `enemyImpactHeight` живут здесь, менять их можно.
3. **Клип живёт от presentation clock, а не от кадра.** `presentationTime` приходит параметром, и
   `animate` должен двигать микшер до него. Это уже оплаченный класс дефекта: если считать иначе,
   поза башни станет функцией порядка кадров и реплей перестанет воспроизводиться.
4. **`reducedMotion` гасит клип и вспышку**, поза и позиции остаются читаемыми.
5. **Никаких новых зависимостей и никаких внешних текстур.** Только примитивы Three.js.
6. **Никаких новых тестов.**

## Проверка

```text
npm run typecheck
npm run build
```

`npm test` запускай, только если свободен — сценарии делят каталог `test-results/` с двумя
параллельными сессиями. Существующие 48 сценариев проверяют форму модуля, которую ты обязан
сохранить, поэтому зелёный прогон здесь ничего нового не скажет.

Свой dev-сервер: `npm run dev -- --port 5175`. Две другие сессии сидят на `5174` и `5176`.

Скриншоты клади в `docs/tasks/0023-tower-look/`, отдельной папкой, которую никто не займёт.
В `docs/screenshots/` не пиши — это зона штаба.

## Ошибка, на которую уже наступали

Комментарий `//` в `src/styles.css` — не комментарий: минификатор съедает следующий селектор,
`npm run build` падает с `Invalid empty selector`, а `npm test` остаётся зелёным. Стили ты не
трогаешь, но `build` проверять обязательно — `npm test` этому не поверит.

## Git

Ветка `main`, коммитить только свой файл поимённо, `git add -A` запрещён. Перед коммитом —
`git status` и `git diff`. Перед push — `git pull --rebase origin main`: две сессии пушат в одну
ветку, и твоя правка должна лечь поверх чужой. Если при rebase есть конфликт — **остановись,
не разрешай силой**, напиши в отчёт. Строгий UTF-8.

## Форма отчёта

Отчёт дописывается в конец **этого файла**, статус меняется на `на проверке`. В отчёте: что
изменил и почему так читается, как три башни отличаются друг от друга и от врага, что осталось
нерешённым, какие чужие файлы тебе понадобились и что ты НЕ стал делать. Скриншоты — рядом
ссылкой на папку.

Принимает владелец, и он решает по игре, а не по отчёту.
