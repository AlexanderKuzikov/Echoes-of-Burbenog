## Контекст (может не быть в CONTEXT.md)

- **Кто пишет код, кто решает.** Кодовая сессия реализует и сдаёт «на проверке», штаб проверяет, принимает и сразу выдаёт следующую задачу. Правило 7: не ждать запроса.
- **Как выдаётся задача.** Промпт кодовой сессии всегда содержит имя проекта, абсолютный каталог `D:\GitHub\Echoes-of-Burbenog` и точные пути к четырём файлам: `AGENTS.md`, `docs/CONTEXT.md`, `docs/PLAN.md`, `docs/tasks/<файл>`. Канонический набор — в разделе «Где искать файлы» в `AGENTS.md`. Сессия, стартовавшая выше корня, получила бы соседний `D:\GitHub\AGENTS.md` — это другой файл.
- **Не мешаем сессии.** Пока сессия работает — не запускать dev-сервер самому: Playwright с `reuseExistingServer` подхватил бы чужой порт, а штаб однажды уже захватил `git add -A` чужую незакоммиченную работу (`916976c`).
- **Проверки приёмки (обязательные).** `npm run typecheck`, `npm run build`, `npm run test:core` (ожидаем `status victory, tick 323, gold 229`), `npm run test:assets` (11 красных проверок), `npm test`, `npx playwright test --repeat-each=2`, `git status` чистый, строгий UTF-8 изменённых файлов, screenshots прочитаны глазами.
- **Playwright на этой машине.** Пин требует `chromium_headless_shell-1243`, установлен `1208`, поэтому E2E идут через `PLAYWRIGHT_EXECUTABLE_PATH='C:\Users\alexa\AppData\Local\ms-playwright\chromium-1208\chrome-win64\chrome.exe'`. Путь в проекте не сохраняется. Установка браузера — только по разрешению владельца.
- **Скриншоты ловят то, что не ловит код.** Три реальных дефекта этого цикла нашлись глазами по кадрам: перекрытие подписи сектора digest'ом (`0010`), обрезанные подписи build palette (`0015`), усечение подписей дока на 560 px (`0017`).
- **Зелёный тест на неработающем коде опаснее красного.** Трижды: `envMapIntensity` без `envMap` (`0011`), посчитанная цена ошибки измерения (`0014`), сценарий Load, читавший фазу из живого DOM (`0016`). Обратная сторона того же класса открылась на приёмке `0018`: **красный тест на зелёном коде** — три утверждения, привязанные к движущимся значениям, упали на нагрузке, и каждое указывало на границу, а не на дефект.
- **Что стоит помнить про решения v1 в `0018`.** Права — про жизненный цикл комнаты, а не про правила матча: строить и запускать волну может любой, `restartRun` и `endRoom` только у `owner`. Кика нет и быть не может без accounts; личность — токен места; reconnect = handshake плюс полный кадр, без дельт. Механика принята; спорить больше не о чем.
