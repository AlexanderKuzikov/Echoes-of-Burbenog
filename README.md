<h1 align="center">Echoes of Burbenog</h1>
<p align="center">LLM-first 3D Tower Defense с постепенным развитием</p>

## Описание

Игра вдохновлена атмосферой и масштабом Warcraft III Tower Defense, особенно референсом Burbenog. Проект строится с нуля: сначала создаётся компактный 3D-ready вертикальный срез, затем расширяются gameplay, графика, сетевые режимы и desktop-сборка.

Ключевая цель разработки — сделать цикл работы максимально удобным для LLM: короткий запуск, детерминированные сценарии, headless-проверки, автоматизированные screenshots и простые границы модулей.

- **3D-ready прототип** — сцена сразу использует XZ-координаты, даже если первый визуальный прототип плоский.
- **LLM-friendly tooling** — Vite, Playwright, structured state и deterministic scenarios.
- **Модульная архитектура** — gameplay, presentation, content и networking развиваются независимо.
- **Solo-first scope** — текущая разработка сфокусирована на одиночной игре; multiplayer остаётся совместимым будущим направлением.
- **Оригинальный visual identity** — собственные модели, арт, палитра и HUD; Burbenog/Warcraft III служат только референсами принципов, а не образцом для копирования.

## Скриншотов нет, и это не пропуск

Публичный набор кадров удалён 2026-10-02. Все пять показывали карту `burrow-vault` — ту, которой на
проекте больше нет: её сменила плоская плита с дорожной сетью по рисунку владельца, а та, в свою
очередь, уступает клеточной модели, где карту рисует сам владелец. Кадр старой карты в новом README
вредит больше, чем его отсутствие.

Правило прежнее: задача, меняющая картинку, снимает новый набор. Следующий набор появится вместе с
первой картой, на которой можно играть, — то есть с клетками, маршрутами и местами для башен.

## Быстрый старт

**Честно о текущем состоянии карты.** Дорожная сеть нарисована по рисунку владельца и лежит в игре
ровно такая, какая на рисунке: двадцать отрезков, четыре входа в край плиты, база в середине. **Играть
на ней нельзя, и это не мелкий недочёт.** Маршруты остались прежними — кольцом на ±45, которого на
плите нет, — поэтому монстры идут по траве в четырёх единицах от дороги, а мест для башен нет вовсе.
Видно правильную картинку, в которую нельзя войти.

**Что решило направление.** Владелец 2026-10-02 зафиксировал клеточную модель: карта — это поле
клеток, у клетки один из трёх видов (свободно, дорога, занято), монстры ходят **только** по дороге,
башни ставятся **только** на свободное, «занято» не пускает ни тех, ни других. Максимальная карта
**96 × 96 клеток**, башня занимает **4 × 4**, дорога — **8 клеток**. Все дробные мировые координаты
прошлой карты отменены вместе с её геометрией.

Карту рисует владелец сам, в отдельном инструменте — [`NexusMap`](https://github.com/AlexanderKuzikov/NexusMap).
Это отдельный проект не ради аккуратности: так на границе остаётся ровно один артефакт, файл карты.
Если редактор жил бы внутри игры, рано или поздно появился бы скрипт-конвертер, а с ним второй путь
от рисунка до игры, и расхождение между ними пришлось бы ловить глазами. Именно этим классом были
испорчены три карты подряд.

Остальное в игре работает и проверено: bootstrap, pure core, двенадцать волн по таймеру с гарантированным
доходом, размещение по местам, бой, пауза, replay по журналу команд, слот матча, экран входа,
authoritative session на Node с местами и правами. Камера свободная: левый драг — орбита с наклоном,
правый — панорама, колесо — зум, `R` возвращает все три параметра, миникарта в рельсе справа от дока.
Скорость игры переключается 0.5× / 1× / 2× / 4× и **не меняет сим**: ускоряется число тиков за кадр,
`TICK_RATE` не тронут.

**Что было проверено на прошлой карте и сейчас уже не про неё.** `picks` 44 из 44 на всех зумах и
азимутах, идентичный терминальный отчёт на 1× и 4× до тика, матч 12.2–12.7 минуты на разумной раскладке
— это замеры карты с нишами, которой больше нет. Как ориентир они остаются верными, как описание
сегодняшней игры — нет. `CONTENT_VERSION` равна 2 и на карте без ниш не поднята, поэтому старый слот
сохранения пройдёт проверку версий и будет переигран на карте, где таких мест нет: каждая команда
поставить башню отклонится. Это файл протокола, работа штаба, не выдана.

**Честно о нерешённом.** Башни и существа — **настоящие модели**, десять штук, приняты из
[`NexusDefense`](https://github.com/AlexanderKuzikov/NexusDefense) и лежат в игре; это больше не причина
чернового вида. Не решено: монстры не тормозят друг друга на дороге, поэтому сплэш по толпе пока не
отличается от сплэша по одиночной цели (`EOB-45`); у трёх башен против семи классов врагов нет выбора
тактики; `tests/` написаны под прежнюю карту, 8 из 48 зелёные, остальные красные и все одного класса
(`EOB-038`) — красный сигнал обесценен, и это цена того, что геометрия карты прибита к тестам.

Проверено: `test:assets` — те же 11 красных проверок, артефакт побайтово прежний; E2E: **8 из 48
зелёные, 40 красные**, набор написан под прежнюю карту 22×14 и прежние имена падов. Живых регрессий в
наборе нет, но красный сигнал обесценен, и это `EOB-038`. `test:core` красный на `niche-corner` —
пада нет на карте с `0025`.


```bash
git clone https://github.com/AlexanderKuzikov/Echoes-of-Burbenog.git
cd Echoes-of-Burbenog
npm install
npm run dev
```

Отдельная проверка:

```bash
npx playwright install chromium
npm test
```

Проверка поднимает и Vite, и сервер сессий сама. Для ручной игры вдвоём в одной комнате:

```bash
npm run server   # в соседнем терминале; порт из src/protocol/index.ts
# затем в двух окнах: http://127.0.0.1:5173/?room=<имя-комнаты>
```

Кто вошёл первым, тот и `owner`: у него включены `Restart` и `End room`, у второго (guest) оба выключены с причиной на подсказке. Строить башни и запускать волну может любой, золото у комнаты одно — это сказано в полосе сессии.

Осторожно с двумя вкладками одного браузера: место хранится в `localStorage`, поэтому вторая вкладка, открытая **после** того, как первая вошла в комнату, предъявит тот же токен места и заберёт его себе, а первая получит отказ «a later connection took this seat». Либо открывайте оба окна до входа в комнату, либо играйте во втором окне в режиме инкогнито или в другом браузере. Это плата за то, что личность в v1 — токен места, а не аккаунт.

## Статус

**Карта в игре не готова, и это главное.** Дорожная сеть по рисунку владельца нарисована и совпадает с
рисунком до знака, но на ней нельзя играть: маршруты остались прежними (кольцо на ±45, которого на
плите нет), монстры идут мимо дороги, мест для башен нет. Всё остальное в игре работает.

**Карта по клеточной модели** — решение владельца от 2026-10-02, принято, ещё не реализовано:

| Что | Значение |
|---|---|
| Поле | клетки, ширина и высота отдельно, максимум **96 × 96** |
| Виды клетки | **свободно**, **дорога**, **занято** — один слой |
| Башня | занимает **4 × 4** клетки |
| Дорога | **8** клеток шириной |
| Правила | монстры ходят **только** по дороге, башни ставятся **только** на свободное, «занято» не пускает ни тех, ни других |

Права выведены из типа клетки, а не из проверок: вне дороги монстру клетки не существует. Из этого
следует и то, что оформление не имеет права разорвать дорогу — иначе волна будет ходить в стену до
конца матча. Проверка достижимости от каждого входа до базы обязана быть в редакторе, а не в приёмке.

**Инструмент:** [`NexusMap`](https://github.com/AlexanderKuzikov/NexusMap), первая работа выдана
2026-10-02. Формат файла карты — `{ version, name, width, height, grid }`, одна строка на ряд, символ
на клетку, чтобы карта читалась глазами в git.

**Остальное, что работает и проверено:** bootstrap, pure core, двенадцать волн по таймеру с
гарантированным доходом, размещение по местам, бой, пауза, replay по журналу команд, слот матча,
экран входа, authoritative session на Node с местами и правами, десять настоящих моделей башен и
существ.

**Волны:** двенадцать, запускаются **по таймеру** с интервалом 1000 тиков независимо от того,
уничтожена ли предыдущая; недобитое копится и уходит дальше само. Гарантированный доход 90 за волну —
1080 за матч без единого убийства, 47% всего дохода, иначе экономика от убийств плюс копящиеся волны
дают спираль. Длительность матча на прошлой карте была 12.2–12.7 минуты и на клеточной будет другой:
маршруты и вся экономика переезжают в клетки, а значит пересчитываются целиком.

**Камера:** левый драг — орбита с наклоном (азимут без ограничения, питч 33°…58°), правый драг —
панорама, колесо — зум, WASD, `R` возвращает все три параметра. Миникарта в рельсе справа от дока,
клик перемещает вид. Регулятор скорости 0.5× / 1× / 2× / 4× ускоряет часы, а не правила: тот же набор
башен на 1× и 4× даёт одинаковый матч до тика.

**Честно о нерешённом:** монстры не тормозят друг друга, поэтому сплэш по толпе не отличается от
сплэша по одиночной цели (`EOB-45`). У трёх башен против семи классов врагов нет выбора тактики. E2E
набор написан под карту, которой больше нет, даёт 8 из 48, и красный сигнал обесценен (`EOB-038`) —
это цена того, что тесты прибиты к геометрии, и переезд на клеточную карту с ним разберётся.
`CONTENT_VERSION` не поднята на смену карты, поэтому старый слот сохранения переиграется на карте без
мест. Лицензия не выбрана, поэтому по умолчанию действует «all rights reserved» (`EOB-008`).
